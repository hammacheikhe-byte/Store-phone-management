# تطبيق فون ماستر (PhoneMaster) - نظام إدارة المنتجات والمخزون والمبيعات والصيانة

تطبيق ويب متكامل ومحمول بالكامل يعمل داخل ملف HTML واحد لا يحتاج إلى سيرفر أو تثبيت برامج، مصمم خصيصاً باللغة العربية لإدارة محلات الهواتف الذكية والمنتجات والم مخزون والصيانة.

## 🚀 طرق التشغيل المباشرة

### الطريقة الأولى: التشغيل التلقائي (Windows)
اضغط مرتين (Double Click) على أحد الملفات التالية لتشغيل التطبيق فوراً في متصفحك:
- `run-windows.bat`
- `start-site.bat`

### الطريقة الثانية: الفتح المباشر للمتصفح
افتَح الملف التالي مباشرة بأي متصفح (Chrome, Edge, Firefox, Safari):
- `index.html`

---

## 🌟 الميزات والمكونات الرئيسية

1. **📊 لوحة التحكم والإحصائيات**:
   - إجمالي عدد المنتجات وقيم المخزون والمبيعات.
   - تنبيهات المنتجات دون الحد الأدنى للمخزون.
   - أحدث الفواتير وحركات المخزون.

2. **📦 إدارة المنتجات والمخزون**:
   - اسم المنتج، كود المنتج (SKU/IMEI)، التصنيف، سعر الشراء والبيع، والحد الأدنى للمخزون.
   - بحث وفلترة سريعة.

3. **📝 سجل حركات وتدقيق المخزون (Audit Trail)**:
   - تسجيل عمليات **إضافة المخزون (تزويد)** و **صرف المخزون**.
   - سجل زمني كامل يعرض التغير في الرصيد والملاحظات والمستخدم.

4. **🛒 الكاشير ونقطة البيع (POS)**:
   - إضافة السلعة للسلة وطباعة فاتورة رسمية.

5. **🛠️ ورشة الصيانة**:
   - تذاكر الصيانة وتتبع الأعطال والتكلفة والأرباح.

6. **🤝 إدارة الموردين والعملاء**:
   - سجل الموردين وشركاتهم وسجل العملاء ومشترياتهم.

7. **🔐 شاشة تسجيل الدخول**:
   - حفظ اسم المستخدم والعمليات باسمه.
